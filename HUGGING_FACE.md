# Model and Dataset Hosting

The custom model and its training dataset are hosted separately
on Hugging Face.

Expected model repository:
`banking-credit-risk-custom-slm-v9`

Expected dataset repository:
`banking-credit-risk-training-dataset`

Check the evaluation report folder for the actual verified
repository identifiers and upload status.

The local Ollama assistant uses Qwen3 4B and is separate from
the custom V9 research checkpoint.

Do not assume that a private Hugging Face repository is
publicly downloadable.
